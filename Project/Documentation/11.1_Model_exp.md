# **Explanation**

### **1. Import Libraries**

The required libraries are imported, including:

- **`train_test_split`**: For splitting the dataset into training and test sets.
- **`StandardScaler`**: For standardizing features.
- **Models**: `LogisticRegression`, `RandomForestClassifier`, `SVC`, `XGBClassifier`.
- **Metrics**: Accuracy, precision, recall, F1-score, and confusion matrix.

---

### **2. Define Features and Target**

```python
y = df['Depression Label']
X = df.drop(columns=['Depression Label'])
```

- `y`: The target variable (`Depression Label`) to be predicted.
- `X`: Features (all columns except `Depression Label`).

---

### **3. Map Target Labels to Start from 0**

```python
y_mapped = y - y.min()
```

- The target values (`Depression Label`) are adjusted to start from 0 to ensure compatibility with models that require class labels starting from 0.

---

### **4. Split the Data**

```python
X_train, X_test, y_train, y_test = train_test_split(X, y_mapped, test_size=0.2, random_state=42)
```

- Splits the data into training (80%) and test (20%) sets.
- `random_state=42` ensures reproducibility.

---

### **5. Initialize the Scaler and Standardize the Data**

```python
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

- **StandardScaler**: Ensures all features have a mean of 0 and a standard deviation of 1.
- **Fit and Transform**:
  - `fit_transform`: Fits the scaler on training data and applies scaling.
  - `transform`: Applies the same scaling to test data.

---

### **6. Logistic Regression**

```python
lr_model = LogisticRegression(max_iter=1000)
lr_model.fit(X_train_scaled, y_train)
y_pred_lr = lr_model.predict(X_test_scaled)
```

- **Model**: Logistic Regression, with a higher iteration limit (`max_iter=1000`) to ensure convergence.
- **Training**: Fits the model to the scaled training data.
- **Prediction**: Predicts labels for the scaled test data.

---

### **7. Random Forest**

```python
rf_model = RandomForestClassifier(n_estimators=100, random_state=42)
rf_model.fit(X_train_scaled, y_train)
y_pred_rf = rf_model.predict(X_test_scaled)
```

- **Model**: Random Forest, an ensemble model with 100 trees (`n_estimators=100`).
- **Training**: Fits the model on the training data.
- **Prediction**: Predicts test data labels.

---

### **8. Support Vector Machine (SVM)**

```python
svm_model = SVC(kernel='linear')
svm_model.fit(X_train_scaled, y_train)
y_pred_svm = svm_model.predict(X_test_scaled)
```

- **Model**: SVM with a linear kernel.
- **Training**: Fits the model to the scaled training data.
- **Prediction**: Predicts test data labels.

---

### **9. XGBoost**

#### Configure the Model:

```python
xgb_model = XGBClassifier(
    use_label_encoder=False,
    eval_metric='mlogloss',
    n_estimators=500,
    learning_rate=0.01,
    max_depth=4,
    subsample=0.7,
    colsample_bytree=0.7,
    reg_alpha=1,
    reg_lambda=1,
    early_stopping_rounds=10
)
```

- **Parameters**:
  - `use_label_encoder=False`: Avoids deprecated warnings.
  - `eval_metric='mlogloss'`: Multi-class logarithmic loss for evaluation.
  - `n_estimators=500`: Maximum trees to build.
  - `learning_rate=0.01`: Small step size for better convergence.
  - `max_depth=4`: Limits tree depth to avoid overfitting.
  - `subsample=0.7`, `colsample_bytree=0.7`: Reduces overfitting by using subsets of data and features.
  - `reg_alpha`, `reg_lambda`: Regularization parameters to prevent overfitting.
  - `early_stopping_rounds=10`: Stops training early if validation performance stops improving.

---

#### Perform Cross-Validation:

```python
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
cv_scores = []

for train_idx, val_idx in cv.split(X_train_scaled, y_train):
    X_train_cv, X_val_cv = X_train_scaled[train_idx], X_train_scaled[val_idx]
    y_train_cv, y_val_cv = y_train.iloc[train_idx], y_train.iloc[val_idx]

    xgb_model.fit(X_train_cv, y_train_cv, eval_set=[(X_val_cv, y_val_cv)], verbose=False)
    y_pred_cv = xgb_model.predict(X_val_cv)
    cv_scores.append(accuracy_score(y_val_cv, y_pred_cv))
```

- **StratifiedKFold**: Ensures class proportions are maintained in each split.
- Splits training data into 5 folds, trains on 4 folds, and validates on the 5th fold.
- Appends validation accuracy to `cv_scores`.

---

#### Fit XGBoost on Full Training Set:

```python
xgb_model.fit(X_train_scaled, y_train, eval_set=[(X_test_scaled, y_test)], verbose=False)
y_pred_xgb = xgb_model.predict(X_test_scaled)
```

- Fits the XGBoost model on the entire training set and validates on the test set.

---

### **10. Evaluation Function**

```python
def evaluate_model(y_test, y_pred, model_name):
    accuracy = accuracy_score(y_test, y_pred)
    precision = precision_score(y_test, y_pred, average='macro', zero_division=0)
    recall = recall_score(y_test, y_pred, average='macro', zero_division=0)
    f1 = f1_score(y_test, y_pred, average='macro', zero_division=0)

    print(f"Model: {model_name}")
    print(confusion_matrix(y_test, y_pred))
    print(f"{model_name} Performance:")
    print(f"Accuracy: {accuracy:.4f}")
    print(f"Precision: {precision:.4f}")
    print(f"Recall: {recall:.4f}")
    print(f"F1-Score: {f1:.4f}\n")
```

- Computes and prints:
  - **Accuracy**: Correct predictions / Total predictions.
  - **Precision**: Fraction of relevant instances among retrieved ones.
  - **Recall**: Fraction of relevant instances retrieved.
  - **F1-Score**: Harmonic mean of precision and recall.
  - **Confusion Matrix**: Displays true positives, false positives, true negatives, and false negatives.

---

### **11. Evaluate All Models**

```python
evaluate_model(y_test, y_pred_lr, 'Logistic Regression')
evaluate_model(y_test, y_pred_rf, 'Random Forest')
evaluate_model(y_test, y_pred_svm, 'SVM')
evaluate_model(y_test, y_pred_xgb, 'XGBoost')
```

- Evaluates each model and prints its performance metrics.
